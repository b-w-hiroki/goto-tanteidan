# 🔍 GO-TO 探偵団

市民参加型防犯アプリのインタラクティブ・プロトタイプ。

市民が「探偵」となり、街のマーキング（侵入犯罪の目印）を発見・投稿。AIが判定し、防犯マップがリアルタイムに育つ仕組みを体験できます。

## デモ

**👉 https://b-w-hiroki.github.io/goto-tanteidan/**

スマホのブラウザで開くと実機サイズのモバイルUIで操作できます。カメラ権限を許可すると実写プレビューで撮影体験ができます（拒否してもダミーモードで動作）。

## 主な機能（すべてダミーデータで動作）

| タブ | 内容 |
|------|------|
| 🏠 ホーム | 探偵プロフィール・警戒度バッジ・今日の活動・捜査ログ |
| 🗺️ マップ | 実地図（Leaflet）にマーキングをピン表示・警戒度ブリーフ・🎬 30日タイムラプス再生 |
| 📸 カメラ | 実カメラプレビュー → 撮影 → AI判定演出 → ポイント獲得 → マップ反映 |
| 🏆 ランキング | 個人ランキング＋探偵団（チーム）⚔️ 週次対抗戦 |
| 📖 手帳 | マーキング図鑑・発見済みコレクション（✓バッジ・コンプ進捗）・防犯クイズ |

### 体験のコアループ

**学ぶ**（クイズ・図鑑）→ **見つける**（街で発見）→ **撮影する**（AI判定）→ **対処する**（警戒度が実際に下がる）→ **振り返る**（📰 週刊 捜査報告書）

### そのほか

## 技術

- 単一HTML（依存はCDN: Leaflet）
- PWA（Service Worker によるオフラインキャッシュ。地図UIも2回目以降はオフライン動作）
- GitHub Pages で自動デプロイ

> これは概念実証用のプロトタイプです。地図・投稿・AI判定・ポイントはすべてダミーデータで動作します。
